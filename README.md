# MiniTAC Compiler

A Python-based educational compiler that demonstrates lexical analysis, syntax analysis, Three-Address Code (TAC) generation, code optimization, control-flow analysis, and program execution.

Built with Streamlit, MiniTAC includes an interactive dashboard to visualize compiler stages, analyze code complexity, eliminate dead code, and understand how a compiler works internally.

## Features

- Lexical and Syntax Analysis
- Abstract Syntax Tree (AST) Generation
- Three-Address Code Generation
- Code Optimization
- Control Flow Graph (CFG)
- Liveness Analysis and Dead Code Elimination
- Optimized TAC Execution and Program Output
- Interactive Streamlit Dashboard
- Code Complexity Analysis
- Learn Mode

## Technologies Used

- Python
- Streamlit
- HTML
- CSS
- Pytest

## Installation and Execution

1. Clone the repository:

   `git clone <repository-url>`

2. Navigate to the project folder:

   `cd MiniTAC-Compiler`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

## Objective

To simplify compiler design concepts through practical implementation and interactive visualization of the complete compilation process.
